### Tổng quan Nhật ký Thực tập (Worklog)

Đây là nhật ký thực tập tốt nghiệp của tôi tại **Công ty TNHH Amazon Web Services Việt Nam**. Nội dung được xây dựng nhằm ghi chép và theo dõi tiến độ học tập, thực hành kỹ thuật, các hoạt động hỗ trợ và kết quả đạt được trong kỳ thực tập kéo dài **12 tuần**, từ tháng **05/2026 đến tháng 07/2026**.

Trọng tâm của kỳ thực tập là nghiên cứu và thực hành nền tảng điện toán đám mây **Amazon Web Services (AWS)**, kết hợp với **ReactJS** để xây dựng và triển khai một ứng dụng web mẫu theo kiến trúc Serverless. Bên cạnh nội dung phát triển ứng dụng, lộ trình còn tập trung vào hạ tầng mạng, lưu trữ, giám sát, bảo mật, sao lưu và tự động hóa vận hành trên AWS.

Dưới đây là tóm tắt lộ trình 12 tuần thực tập, từ việc làm quen với tổ chức và các khái niệm nền tảng, thực hành hạ tầng AWS, xây dựng Demo Web App, đến việc hoàn thiện Workshop, triển khai production và tổng hợp báo cáo thực tập:

**Tuần 1:** [Tìm hiểu tổng quan về công ty, văn hóa AWS, tài khoản root và IAM](1.1-week1/)

**Tuần 2:** [Thực hành EC2, VPC, Subnet, Security Group và nghiên cứu Cloud Computing](1.2-week2/)

**Tuần 3:** [Khám phá AWS Lambda, API Gateway và triển khai Demo Web App lên AWS](1.3-week3/)

**Tuần 4:** [Nghiên cứu kiến trúc đám mây và thực hành Amazon S3, Amazon EBS](1.4-week4/)

**Tuần 5:** [Thiết lập metrics giám sát và quản lý dịch vụ bằng AWS CLI](1.5-week5/)

**Tuần 6:** [Truy xuất CPU Utilization, Network In/Out và thiết lập CloudWatch Dashboard](1.6-week6/)

**Tuần 7:** [Triển khai ReactJS SPA lên S3 và phân phối bảo mật qua CloudFront](1.7-week7/)

**Tuần 8:** [Cấu hình CloudWatch Logs, Alarms và quản lý máy chủ bằng AWS Systems Manager](1.8-week8/)

**Tuần 9:** [Quản lý IAM Permission Boundaries, VPC Flow Logs, AWS Backup và hỗ trợ sự kiện First Cloud Security Journey](1.9-week9/)

**Tuần 10:** [Thực hành lab bảo mật với Security Hub, GuardDuty, Macie, Network Firewall và xây dựng ý tưởng Workshop](1.10-week10/)

**Tuần 11:** [Hoàn thiện kịch bản demo, tài liệu kỹ thuật và deploy website lên production bằng automation](1.11-week11/)

**Tuần 12:** [Tổng hợp dữ liệu, hoàn thiện báo cáo thực tập, nộp về Khoa và tham gia tổng kết tại công ty](1.12-week12/)
