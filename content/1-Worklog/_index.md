### Internship Work Log Overview

This **Internship Work Log** documents my learning progress, technical practice, and professional activities during a **12-week internship** from **May 2026 to July 2026** at **Amazon Web Services Vietnam**.

The primary focus of the internship was to study and apply **Amazon Web Services (AWS)** cloud technologies together with **ReactJS**. The roadmap covered cloud infrastructure, serverless application development, storage, monitoring, security, backup, automation, and Workshop preparation.

The following is an overview of my 12-week internship journey, from organizational orientation and foundational AWS practice to advanced security labs, production deployment, and completion of the graduation internship report.

**Week 1:** [Company structure and AWS corporate culture orientation; root account creation and secure IAM permission configuration](1.1-week1/)

**Week 2:** [Basic labs with EC2, isolated VPC infrastructure, Subnets, and Security Groups; Cloud Computing research](1.2-week2/)

**Week 3:** [AWS Lambda and API Gateway exploration; Demo Web App deployment to AWS for data-connectivity testing](1.3-week3/)

**Week 4:** [Cloud architecture design solutions; Amazon S3 and Amazon EBS creation, management, and security practice](1.4-week4/)

**Week 5:** [System monitoring metric configuration and cloud service management using the AWS CLI](1.5-week5/)

**Week 6:** [Performance metric queries for CPU Utilization and Network In/Out; AWS CloudWatch Dashboard configuration](1.6-week6/)

**Week 7:** [ReactJS SPA static website deployment to Amazon S3; performance optimization and SSL security through AWS CloudFront CDN](1.7-week7/)

**Week 8:** [Advanced logging with CloudWatch Logs and Alarms; virtual-server configuration management and security patching with AWS Systems Manager](1.8-week8/)

**Week 9:** [Advanced IAM permissions with IAM Permission Boundaries; VPC Flow Logs; automated EBS backups with AWS Backup; technical support for the First Cloud Security Journey event](1.9-week9/)

**Week 10:** [Advanced security lab practice with Security Hub, GuardDuty, Macie, and Network Firewall; technology Workshop content development](1.10-week10/)

**Week 11:** [Final Workshop demo scripts and technical documentation; complete website deployment to production through cloud automation](1.11-week11/)

**Week 12:** [Data synthesis, document-format review, and finalization of the graduation internship report for Faculty submission; support for end-of-internship company events](1.12-week12/)
